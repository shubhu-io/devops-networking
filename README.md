# 🌐 03-devops-networking — Networking & Connectivity Execution Repository

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Learning Hub](https://img.shields.io/badge/DevOps-Learning%20Hub-blue.svg)](https://github.com/shubhu-io/devops-learning)

Practical networking diagnostics laboratory covering TCP/IP, DNS troubleshooting, port scanning, and HTTP health checks.

---

## ⚡ Quick Start

```bash
git clone https://github.com/shubhu-io/03-devops-networking.git
cd 03-devops-networking
chmod +x setup.sh
./setup.sh
```

Execute network diagnostic utilities:
```bash
./scripts/network-audit.sh
./scripts/port-scanner.sh 127.0.0.1 80
./scripts/web-health.sh https://httpbin.org/get
```

---

## 📂 Repository Structure
- `scripts/`: Production network auditing Bash scripts.
- `labs/`: Hands-on DNS and network diagnostics labs.
